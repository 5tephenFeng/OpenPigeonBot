## 取舍

- locale 硬编码字样暂未改，留待用户决定。不要在分支上批量改 JSON 源文件，也不要做无差别运行时 `replaceAll`。`src/lib/i18n.ts` 的 `t()` 已把 `{app}` 换成 `productName()`，这是更合适的出口。
  实测统计（`opb/branding`，16 个 locale JSON，子串 `MausBot`，含出现在 `OpenMausBot` 中的）：全部文件 1699 处（其中 `OpenMausBot` 373 处）；`en.json` 203 处、191 个词条。`en.json` 另有 227 个词条使用 `{app}`。此前「约 80 处」不准确。
  不应改名的对象：MausBot Cloud、the MausBot team（指上游维护者）、MausBot Relay、官方手机伴侣文案（如 “Update MausBot on your phone”）、CLI 命令（如 ``openmausbot browser install``，见 `settings.experimental.browserWindows`）。locale 中未出现 `openmausbot://`；大小写敏感的替换通常不会碰到 scheme，但忽略大小写就会伤到 CLI。
- 图标尚未更换，完整资源如下（不只是打包用的 3 个文件）：
  - 打包配置引用：`build/icon.icns`（mac）、`build/icon.ico`（win）、`build/icon.svg`（linux）
  - 同目录其它源：`build/icon-1024.png`、`build/icon.html`、`build/icon.iconset/` 下 10 张 PNG
  - 托盘 / 未读角标 / lending tray：`electron/resources/app-icon.png`（`electron/main.mjs` 中的 `APP_ICON`）
  - Web / favicon：`public/app-icon.svg`、`public/app-icon-192.png`、`public/app-icon-512.png`、`public/apple-touch-icon.png`；`index.html` 与 `public/manifest.webmanifest` 引用了这些路径
  若用户决定更换，应一并替换上述会进入界面的资源。
- 数据目录不改为 `~/.openpigeonbot`，继续用 `~/.openmausbot`，以免拆开已有数据并破坏合同。
- 服务端 `/api/brand` 默认名保持 `OpenMausBot`。`productName()` 和 `document.title` 在 `source !== "file"` 时保持 PigeonBot。直接读取 `brand().name` 的展示点待排查，不在未列出调用点之前改服务端合同或盲目加一层覆盖。
- Linux 可执行文件名在配置里仍是 `executableName: openmausbot`（本次未作为产品目标验证）。
- 不在 `main` 上提交这些改动，以便继续快进同步上游。
